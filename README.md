# RangerStarter

Ranger Starter Pack

## What you need to start development

This repository is currently a minimal starter, so you only need a few basics to get going:

- Git
- A GitHub account with access to this repository
- A code editor or IDE
- The runtime and tooling for the stack you want to build here

## Start development

1. Clone the repository.
2. Open it in your editor.
3. Add the project files for the stack you want to use.
4. Define your build, test, and lint commands as part of the initial project setup.
